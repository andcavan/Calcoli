Formule utilizzate
Rapporti geometrici — qa = di/d (albero, 0 se pieno) · qm = d/De (mozzo)
Interferenza efficace (DIN 7190) — δ_eff = δ − 0,8·(Rz_albero + Rz_mozzo)  [µm]
Pressione di contatto (Lamé, δ in mm) —
  p = δ / { d · [ (1/Em)·((1+qm²)/(1−qm²) + νm) + (1/Ea)·((1+qa²)/(1−qa²) − νa) ] }
  albero pieno (qa = 0) → il secondo termine diventa (1 − νa)/Ea
  p_min da δ_eff,min (aderenza) · p_max da δ_eff,max (resistenza)
Capacità di trasmissione (con p_min) —
  Fa_max = µ·p_min·π·d·L  [N]  ·  Mt_max = µ·p_min·π·d²·L/2  [N·mm]
  carichi combinati: √( (2·Mt/d)² + Fa² ) ≤ µ·p_min·π·d·L
Tensioni nel mozzo (pressione interna, punto critico al foro) —
  σ_t = +p_max·(1+qm²)/(1−qm²)  ·  σ_r = −p_max
  σ_id (Tresca) = σ_t − σ_r = 2·p_max/(1−qm²)
Tensioni nell'albero —
  pieno: σ_t = σ_r = −p_max (compressione idrostatica) → σ_id ≈ 0
  cavo: σ_t al foro = −2·p_max/(1−qa²) → σ_id = 2·p_max/(1−qa²)
Montaggio —
  piantaggio a freddo: F_press = µ_press·p_max·π·d·L  [N]
  riscaldamento mozzo: ΔT = (δ_eff,max + gioco)/(α_mozzo·d) → T = T_amb + ΔT
  raffreddamento albero: ΔT = (δ_eff,max + gioco)/(α_albero·d) → T = T_amb − ΔT
